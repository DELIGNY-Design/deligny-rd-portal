# DELIGNY R&D Portal

Portail public pre-SASU pour regrouper les logiciels DELIGNY R&D sans activer la vente publique.

## Role

- Acces aux logiciels et prototypes.
- Store prepare, paiement public desactive.
- Desk client futur.
- Separation claire entre Atlas, outils gratuits, R&D et projets prives.

## Garde-fous

- Pas d'adresse personnelle publiee.
- Pas de paiement en ligne.
- Pas de NEO/trading dans le parcours commercial.
- Mentions legales et CGV completes a poser apres domiciliation SASU.
